# Welcome to the Lurch Discussion Files Repository

This repository is a place to store example Lurch documents so that they can be linked to in forum discussions like those in the Lurch channel at code4math.  This allows share a link such as 

`https://lurch.plus/instructor.html?load=https://kenmonks.github.io/lurch-discussion-files/welcome.lurch`

to a file such that it will open directly in Lurch when a user clicks on it. If you would like to be able to post files here, [contact me](mailto:ken.monks@sgmail.com).
